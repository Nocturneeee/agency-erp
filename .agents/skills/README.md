# Workspace Skills for Antigravity & Agent Workflows

## 1. Superpowers Skills
Installed from [obra/superpowers](https://github.com/obra/superpowers) (v7.0.2).

- **brainstorming**: Interactive design and requirement discovery before writing code or planning.
- **systematic-debugging**: Systematic, evidence-based debugging procedure.
- **test-driven-development**: Test-driven development workflow (TDD).
- **writing-plans**: Implementation planning for multi-step tasks.
- **executing-plans**: Step-by-step plan execution.
- **subagent-driven-development**: Parallel or delegated plan execution via subagents.
- **dispatching-parallel-agents**: Orchestrating independent subtasks concurrently.
- **requesting-code-review**: Comprehensive code review requests before merging.
- **receiving-code-review**: Handling code review comments with technical rigor.
- **verification-before-completion**: Verifying all requirements and tests pass before declaring completion.
- **finishing-a-development-branch**: Clean branch integration and final verification.
- **using-git-worktrees**: Worktree-based task isolation.
- **using-superpowers**: Meta-skill establishing automatic invocation rules.
- **writing-skills**: Guide for creating and verifying new skills.
- **diagnosing-superpowers**: Diagnostic tool for troubleshooting agent behavior.

## 2. Ponytail Skills
Installed from [DietrichGebert/ponytail](https://github.com/DietrichGebert/ponytail).

- **ponytail**: Lazy senior dev working mode. The smallest complete change that solves the problem (YAGNI, stdlib first, reuse existing code).
- **ponytail-review**: Code review pass focused on hunting over-engineering, unneeded dependencies, and bloat.
- **ponytail-audit**: Full-repo quality and simplicity audit to identify dead code, bloat, and consolidation targets.
- **ponytail-debt**: Scans code for shortcut comments (`shortcut:`) to track deliberate technical compromises.
- **ponytail-gain**: Reports code reduction, efficiency, and benchmark impact.
- **ponytail-help**: Quick reference guide for Ponytail commands, levels (`lite`, `full`, `ultra`), and flags.
